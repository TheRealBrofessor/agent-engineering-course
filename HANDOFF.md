# Agent Engineering Course — handoff

The complete runnable course is in `/root/agent-engineering-course`. Tier 0→7 remains strictly sequential. Read each lesson, create the named learner artifact under `work/tier-N/`, run the active check, write evidence, and submit with `--attest`. `status` is read-only and never imports learner code. Advanced checks use short-lived, credential-free subprocesses and deterministic fixtures; they are containment, not a hostile-code sandbox. Providers remain optional to the advanced labs and no `.env` or saved credentials are read.
