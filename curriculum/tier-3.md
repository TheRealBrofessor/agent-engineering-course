# Tier 3 — Evaluation

**Status: roadmap only; validator unavailable.** Prerequisite: Tier 2 gate passed. Promotion stays closed until its lab is built.

## Concept and cumulative project
A plausible answer is not a measured answer. Build a held-out set for the Tier 2 help-desk agent: answerable questions, ambiguous questions, and questions with no supporting document. Separate retrieval quality from generation quality; compute deterministic citation coverage, refusal behavior, and answer-support checks before considering a local-model judge. A small local judge may be inconsistent, so compare its score to human-reviewed examples and keep raw evidence.

## Planned learner artifact
A repeatable evaluation script, a versioned question set, baseline results, and a change that improves one metric without hiding regressions. Report denominators and failure cases instead of one flattering aggregate number.

## Gate target
Demonstrate a held-out evaluation run, explain at least two measured failures, and show a before/after comparison with the same questions. The Tier 3 validator is **not shipped** in this release; no rubric score or NVIDIA-specific hosted evaluation is claimed. The later lab must stay keyless.
