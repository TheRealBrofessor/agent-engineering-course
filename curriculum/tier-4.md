# Tier 4 — Customization

**Status: roadmap only; validator unavailable.** Prerequisite: Tier 3 gate passed. Promotion remains closed.

## Concept and cumulative project
Specialize the cumulative agent by changing the cheapest, most inspectable layer first: instructions, tool design, retrieval data, then a portable skill. Use Tier 3's held-out set to compare the same tasks before and after customization. Training is an optional advanced branch, not an assumed requirement. CPU-only hardware may make reinforcement learning or GPU-specific recipes impractical; do not mark those exercises complete by substituting an unmeasured prompt tweak.

## Planned learner artifact
A domain skill for a bounded CLI workflow, a baseline-vs-customized scorecard, synthetic tasks with verifiable outcomes, and an approval step before executing any state-changing command. Keep generated data and reward rules auditable.

## Gate target
Show a reproducible improvement or an honest negative result, explicit command-approval behavior, and a failure analysis from the held-out set. The Tier 4 validator is **not shipped**; this roadmap neither trains a model nor claims a GPU result. Use the provider configuration from Tier 0.
